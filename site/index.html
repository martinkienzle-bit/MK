Benachrichtigungen

SpaWater prüft fällige Aufgaben beim Öffnen und zeigt dann eine Benachrichtigung, sofern du sie erlaubst und dein Browser sie unterstützt. Eine reine Offline-PWA kann nicht auf jedem Android-Gerät zuverlässig erinnern, wenn sie vollständig geschlossen ist.

Datenschutz & Backup

Alle Messwerte und Pflegepläne bleiben im lokalen Speicher dieses Browsers. Keine Konten, keine Synchronisierung, keine Übertragung an einen Server. Browserdaten nicht löschen; sichere deine Daten gelegentlich als JSON-Backup.
