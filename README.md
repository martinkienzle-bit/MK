# SpaWater für Android

Offline-Whirlpool-Pflege-App für Android. Die Daten bleiben lokal auf dem Gerät.

## APK bauen
GitHub Actions startet den Build bei jedem Push auf `main` oder manuell über **Actions → Build SpaWater APK → Run workflow**. Die fertige Debug-APK liegt danach im Workflow-Lauf unter **Artifacts**.

Hinweis: Debug-APK, nicht für den Play Store signiert.
